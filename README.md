# Noé Peverelli — engineering portfolio

Apprentice power electronics engineer at Safran Electronics & Defense (Valence R&D centre) since September 2025, and M1 FISA student in the 3EA department of INP-ENSEEIHT.
This Jekyll site, published with GitHub Pages at https://nono-vep.github.io/Portfolio-Noe-PEVERELLI/, presents my projects, my Career Evolution Plan (/cep/), my international mobility plan and my CVs.
Local build: `bundle install && bundle exec jekyll serve`; after editing the deck, re-export the CEP slides with `python3 tools/export_cep_images.py` (needs `pip install pymupdf`).
